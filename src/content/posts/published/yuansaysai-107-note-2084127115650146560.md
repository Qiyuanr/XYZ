GitHub Agent 周榜｜2026.07.27-2026.08.02

这周 GitHub Trending 里，我筛出 5 个更值得 Codex / Claude Code / Cursor 用户装上的项目：

1⃣️ OpenCodeReview
⭐ 17.9K Stars｜🚀 本周 +4.4K

给 PR 审查补一层确定性规则 + LLM Agent，少一点噪音评论，多一点真正能落到行级别的审查意见。

2⃣️ ego-lite
⭐ 7.7K Stars｜🚀 本周 +3.6K

把已登录浏览器状态共享给 Codex / Claude Code，用并行 Spaces 跑网页任务，不抢你的标签页和鼠标。

3⃣️ OpenWork
⭐ 20.4K Stars｜🚀 本周 +2.9K

把同一套 skills、MCP、连接器抽成共享工作区，Codex / Claude Code / Cursor 可以复用同一层能力。

4⃣️ i-have-adhd
⭐ 15.7K Stars｜🚀 本周 +5.2K

它不加新工具，但能让 coding agent 更稳定地先给结论、再展开步骤，长任务更好扫读。

5⃣️ T3 Code
⭐ 16.4K Stars｜🚀 本周 +1.4K

如果你的 Codex / Claude / Cursor 已经装在本机上，它能把这些会话接到手机、Web 和桌面端远程控制。
