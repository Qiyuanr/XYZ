拼贴信息动画 Skill 正式开源
链接在评论区

之前开源的拼贴 B-roll 有个隐患：全片都是隐喻动画，观众会审美疲劳。所以给它做了个搭档——同一套米色纸场、卡纸剪片、半调质感，专管「讲信息」的段落：数字、流程、清单、对比。B-roll 讲情绪，info 讲信息，两个穿插着排，不跳戏也不疲劳。

工作流程如下:
1、丢一份口播逐字稿进去
2、AI 挑出适合做信息动画的句子，每句分配一种主动效，八种全片不重复
3、Gate 1 确认选段名单
4、Gate 2 headless Chrome 截静态样帧，确认构图
5、Gate 3 才跑动画：HyperFrames 渲染 + 卡纸拟音 + 逐帧 QA
6、交付 1080×1920 竖版 mp4，每条动画的收帧就是一张可读海报

Tips: 这次连 API 都不用接——纯 HTML/CSS/GSAP 本机渲染，不调任何图片模型。改样帧几乎零成本，所以三道门拦的不是钱，是返工：样帧没过就不动画，收帧永远等于你确认过的那张样帧。

画面纪律：一件信息 = 一张卡纸剪片，一帧只有一处点色；真实截图过半调处理，拿不到截图就用灰条占位，绝不画假界面；屏幕文字只用逐字稿里有的事实，不替你编数据。

备注: 只做无角色信息图；情绪独白归拼贴 B-roll 或实拍，界面演示归录屏，不硬做

MIT 开源，Claude Code 直接可用，clone 下来就能跑
